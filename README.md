# GMS-0047 · Point-Voxel Soldier

Интерактивный 3D-персонаж (WebGL / Three.js) в одном HTML-файле: векторный 3D-сканер референса строит плотную сетку узлов (2–3 мм) с Z-рельефом, нормалями и цветом, а затем собирает из неё монолитный меш.

## Запуск
Откройте `soldier.html` в браузере (нужен интернет — Three.js грузится с CDN). Никакой сборки не требуется.

## Структура
- `soldier.html` — всё приложение: пульт управления, сканер референса, риг из 23 костей, анимации (T-Pose / Idle / Walk / Run), три режима рендера, экспорт GLB/OBJ.
- `reference/` — изображения-референсы (можно загружать в пульте кнопкой «ЗАГРУЗИТЬ РЕФЕРЕНС»).
- `.github/` — CI (проверка синтаксиса модульных скриптов) и служебные скрипты.

## Режимы рендера (секция «04 РЕНДЕР» пульта)
- **СЕТКА** — соседние узлы соединяются в треугольные плоскости (3 точки = плоскость), передняя и задняя оболочки + стены по границе силуэта; кнопкой «ЛИНИИ СЕТКИ» включается wireframe-каркас.
- **СЛИЯНИЕ** — узлы сливаются шейдером в монолитную поверхность (сплэты по нормалям).
- **ТОЧКИ** — классическое облако точек.

## Экспорт
Кнопки «Скачать .GLB» / «Скачать .OBJ»: иерархия костей + клипы Idle/Walk/Run (30 fps). Для Unity — glTFast / UniGLTF.
