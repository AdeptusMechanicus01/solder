# GMS-0047 · Point-Voxel Soldier

Интерактивный 3D-персонаж (WebGL / Three.js) в одном HTML-файле. Конвейер: пустое 3D-поле → загрузка 4 референсов (фронт / лево / право / зад) → разбор картинки на пиксели-точки и векторы с выдавливанием по яркости (ярче = выступает, темнее = глубже) → сращивание 4 видов в 3D-модель → оживление (T-Pose / Idle / Walk / Run).

## Запуск
Откройте `soldier.html` в браузере (нужен интернет — Three.js грузится с CDN). Никакой сборки не требуется.

## Структура
- `soldier.html` — всё приложение: пульт управления, 4 слота референсов, воксельное сращивание видов, риг из 23 костей, анимации (T-Pose / Idle / Walk / Run), три режима рендера, экспорт GLB/OBJ.
- `reference/` — изображения-референсы (загружаются в слоты секции «02 РЕФЕРЕНСЫ · 4 ВИДА»; кнопка «ДЕМО» заполняет все 4 слота рендерами встроенного каркаса).
- `.github/` — CI (проверка синтаксиса модульных скриптов) и служебные скрипты.

## Конвейер сборки
1. При старте 3D-поле пустое.
2. Загрузите референсы в 4 слота (или нажмите «ДЕМО · 4 ВИДА С КАРКАСА»). Минимум — один вид (фронт); для полного объёма нужны все 4.
3. Каждый вид разбирается на пиксели-точки: маска силуэта, яркость, distance transform; коэффициент выдавливания = 30% выпуклость от края + 70% яркость.
4. «ПОСТРОИТЬ 3D МОДЕЛЬ»: лёгкое облако точек — каждый пиксель вида становится одной 3D-точкой, выдавленной по яркости вдоль оси вида; рендер через WebGL gl.POINTS (миллионы точек без нагрузки на процессор). Фронт — базовая структура: точки разных видов дедуплицируются в общую сетку (без наслоения), связи-соседи определяются один раз при построении. Режим СЕТКА строит лёгкие 2.5D-оболочки из фронт/зад видов (3 точки = плоскость), шаг сетки не мельче 8 мм.
5. Оживление: модель привязана к ригу из 23 костей — T-Pose / Idle / Walk / Run, экспорт GLB с клипами.

Слайдеры: «Выдавливание» (глубина рельефа 60–300 мм), «Ячейка» (2–20 мм), «Размер точки».

## Режимы рендера (секция «04 РЕНДЕР» пульта)
- **СЕТКА** — соседние узлы соединяются в треугольные плоскости (3 точки = плоскость), передняя и задняя оболочки + стены по границе силуэта; кнопкой «ЛИНИИ СЕТКИ» включаются линии-соседи (LineSegments, индексы считаются один раз при построении).
- **СЛИЯНИЕ** — узлы сливаются шейдером в монолитную поверхность (сплэты по нормалям).
- **ТОЧКИ** — классическое облако точек.

## Экспорт
Кнопки «Скачать .GLB» / «Скачать .OBJ»: иерархия костей + клипы Idle/Walk/Run (30 fps). Для Unity — glTFast / UniGLTF.
